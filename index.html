Things I've Built

HelpHub – Medical Crowdfunding Platform

A medical crowdfunding website where patients, hospitals, donors and admins manage funding requests and donations.

Python Django MySQL HTML CSS JavaScript
GitHub

About HelpHub

HelpHub is a full-stack web application developed using Django and MySQL to manage medical fundraising in a structured and transparent way.

  • Four roles: Admin, Hospital, Patient, and Donor.
  • Admin: Manages users, approvals, categories, and funding requests.
  • Hospital: Registers patients, manages funding, expenses, and donations.
  • Patient: Tracks funding, donations, and provides feedback.
  • Donor: Views approved cases and makes donations.
  • Funding: Tracks required, collected, and remaining amounts.
  • Database: Manages users, donations, funding, expenses, and feedback using MySQL.

Goal: Build a platform where hospitals can raise funds for patients' treatment and donors can give with clear records.

Solution: A Django + MySQL system with four roles (Admin, Hospital, Patient, Donor). Admin approves hospitals and requests, hospitals register patients and expenses, and donors donate through a demo payment page.

Learned: Database design, DFDs, workflows, and testing each module manually.

GPS Toll – GPS-Based Toll Collection System

A GPS-based toll collection system that helps users locate toll points, manage vehicles, pay tolls, and track toll-related information.

Python Flask Java Android MySQL Java Swing
GitHub

About GPS Toll

A GPS-enabled toll management application developed to simplify toll payment and provide location-based toll information.

  • User: Registers, logs in, and manages vehicle details.
  • GPS: Helps users identify nearby toll locations.
  • Toll payment: Users can view toll charges and make payments.
  • Wallet: Users can manage their balance and payment history.
  • Fine management: Users can view and pay applicable fines.
  • Information: Provides toll locations, districts, and toll amounts.
  • Management: Java Swing is used for managing toll-related data.

Goal: Build a toll system where vehicles pay automatically and speeding gets a fine, without stopping at a toll gate.

Solution: Three parts sharing one MySQL database: a Flask admin panel for toll places, rates and fines, an Android app with wallet and payments, and a Java Swing simulator that sends a vehicle's location and speed.

Learned: How a web app, a mobile app and a Java program work with the same database, plus database design, DFDs and manual testing.

Velora Fragrances – E-Commerce Website

A full-stack perfume e-commerce platform with product browsing, user accounts, shopping cart, online payments, reviews, and AI-powered search.

Python Django DRF MySQL JavaScript Razorpay AI
GitHub Live Demo

About Velora Fragrances

A full-stack e-commerce application built with Django, MySQL, and JavaScript for selling perfumes online.

  • Products: Browse perfumes, categories, prices, ratings, and details.
  • Authentication: User signup, login, logout, and session management.
  • Cart & Orders: Add products, manage quantities, checkout, and view order history.
  • Payments: Supports Razorpay online payments and Cash on Delivery.
  • AI Search: Natural-language product search and AI-powered recommendations.
  • Reviews: Users can rate and review products with 1–5 star ratings.
  • REST API: Django REST Framework connects the frontend with the backend.

Goal: Build a real perfume store where customers can search in normal sentences, with proper login and online payment.

Solution: I built it with Django, MySQL and JavaScript. It has AI search, a cart, Razorpay and Cash on Delivery, reviews and order history, and I deployed it on Render, Aiven and Netlify.

Learned: Database design, connecting Razorpay payments, using AI search with real database results, and deploying a frontend and backend separately.

TripZy – Travel Website

A travel website I made with HTML, CSS and JavaScript. It has travel packages, a photo gallery, a booking form, login and register popup, and a search bar that filters the packages.

HTML CSS JavaScript Swiper.js Responsive
GitHub Live Demo

About TripZy

A front-end travel website built with plain HTML, CSS and JavaScript. The forms are demo only and save data in the browser.

  • Home: Background video with 3 videos to switch between.
  • Search: Type a place and it shows only that package.
  • Packages: 7 destinations with prices and star ratings.
  • Booking: Form that checks the arrival and leaving dates.
  • Login & Register: Popup form, saved in localStorage (demo).
  • Contact: Form with email and phone number checks.
  • Gallery: A separate page with many travel photos.
  • Responsive: Works on phones with a menu button.

Goal: Build a responsive travel website where users can explore packages, search places and book a trip.

Solution: I used only HTML, CSS and JavaScript. It has a video hero, package search, login and register, a booking form with date checks, and a contact form. There is no backend, so the data is saved in the browser with localStorage as a demo.

Learned: DOM handling, form validation, localStorage, responsive layouts and Swiper sliders.
